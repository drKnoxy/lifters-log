# lifters-log
An online calculator for wendler's 5/3/1 lifting method.

Built with [Preact](https://preactjs.com), TypeScript and [Vite](https://vite.dev). Requires Node 22+ (see `.nvmrc`).

```sh
npm install
npm run dev       # local dev server
npm test          # unit tests
npm run build     # typecheck + build to dist/
npm run preview   # serve the built dist/
```

Pushing to `gh-pages` deploys via GitHub Actions (`.github/workflows/deploy.yml`).
